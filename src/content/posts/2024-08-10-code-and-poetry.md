## 两种语言

我是一个写代码的人，也是一个写诗的人。

这两个身份在很多人看来是矛盾的。代码是理性的、精确的、功能性的；诗歌是感性的、模糊的、审美性的。但在我看来，它们只是同一种能力的两种表现形式：对语言的精确控制。

## 代码的韵律

好的代码和好的诗歌一样，都有韵律。

```python
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)
```

这段代码的简洁和递归结构，像一首短诗。每一行都在说一件事，没有多余的词。

## 诗歌的逻辑

反过来，诗歌也有逻辑。

> "黑夜给了我黑色的眼睛，我却用它寻找光明。"

顾城的这句诗，逻辑严密得像一个条件语句：如果（黑夜给了我黑色的眼睛），那么（我用它寻找光明）。但在这个逻辑框架内，情感的力量却得到了最大程度的释放。

## 精确性的不同面向

代码追求功能上的精确：输入 A，必须输出 B。诗歌追求情感上的精确：这个词、这个韵脚、这个停顿，必须准确地传达某种难以名状的情绪。

两种精确，殊途同归。

## 结语

所以我常常对想学编程的文科生说：如果你有写诗的经验，你已经具备了编程最重要的能力——对语言的敏感。反过来，程序员如果想学写作，他们已经拥有了最宝贵的技能——把复杂的事情说清楚。

代码和诗歌，都是人类用语言对抗混沌的方式。
